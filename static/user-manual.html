USER REFERENCE | VERSION 1.0.42

User Manual

Current guidance for data collection, REDCap loading, analysis, and the local report assistant.

Return to application

Sign in and choose work

  1. Sign in with the application credentials provided by the administrator.
  2. Open Data Collection and select Inventory, Profiling, or Gap Analysis.
  3. Group users see only their assigned phase and tools or domains. Coordinators see all assigned work and reports.
  4. Use My Entries to review work saved through a group account.

Open assessment data

  1. On Inventory, select a country and reporting month/year in Assessment data.
  2. Select Load REDCap data for an existing assessment.
  3. Select Add new data for a blank assessment.
  4. Confirm the displayed country and reporting period before entering or saving data.

Loading data does not write it back to REDCap or create a duplicate record.

Temporary Test Country

Test Country is reserved for temporary non-production testing. Its entries and imports remain in memory, are never saved to REDCap, and disappear when the application closes or restarts. Confirm the status says Test Country: temporary only - not saved to REDCap. Use an approved UAT country when REDCap persistence must be tested.

Enter and save data

  • Inventory: add surveillance systems, complete the available fields, and save Inventory.
  • Profiling: select each inventoried system, complete every relevant response and its separate comment, including Opportunities & Challenges, and save Profiling.
  • Gap Analysis: select an assigned domain, complete its questions, explanations, comments, findings, and recommendations, then save.
  • Wait for the successful save or temporary-only message before changing items or closing the application.

After standard Excel import, data should display immediately without a browser refresh. Blank dropdowns must show No response; verify system names, platforms, implementation years, coverage, diseases/events, and all open-ended responses.

Generate analysis

  1. Open Analysis.
  2. Select Inventory, Profiling, or Gap Analysis.
  3. The active assessment country and period appear automatically. Change either filter when another report is required.
  4. Select Generate Report.
  5. Use Download Word, Print / Save PDF, Summary Report, or Visual Dashboard as required.

Generating a report does not modify REDCap data or replace the active data-entry workspace. The brief Profiling summary uses Overview, Key capabilities, Main gaps and challenges, Reported priority actions, and Data validation. National totals count only explicit national-level responses; blank and subnational responses are excluded. Domain-score affirmative/scored totals are answer counts, not system counts; data exchange is reported separately using the Profiling system denominator.

Use the report assistant

When the header shows Local AI - qwen3:4b-instruct, the selected report is processed locally by Ollama on this computer.

  • Use Professional report, Discuss all tables, Unified DHIS2 toolkit, Thematic analysis, Action plan, Executive summary, or a typed question.
  • Simple responses normally begin sooner. Complex responses can take one or more minutes and stream into the chat.
  • For consolidated recommendations, each proposed action must identify its supporting finding and must not transfer evidence between systems.
  • Standard Unified DHIS2 toolkit output does not include a separate Validation gates and indicators section or an automated Evidence check warning listing unsupported numerical expressions. Request specific indicators separately if needed.
  • The assistant receives the selected report, supporting evidence when required, your question, and short chat history. It does not receive passwords or REDCap tokens.
  • Select Download latest response in Word after a response finishes to save it as a formatted Microsoft Word document. Before sharing, confirm the removed validation-gates section and numerical-expression warning are absent.
  • Verify important findings and treat AI-generated actions as proposed recommendations.

Generate and download charts

  1. Generate the required report.
  2. Ask the assistant: Generate charts from this report.
  3. The app opens the graph view and creates charts from the report data already loaded in the app.
  4. Select Download charts as PNG to save one high-resolution image containing the available charts.

The charts currently cover system types, surveillance-function coverage, responsible units, and API availability. Chart calculations are local and deterministic; Ollama does not invent their values. Totals for multi-select categories may exceed the number of systems.

Offline use

  • Ollama analysis, chart generation, Word export, and PNG download work without internet when the selected report is already loaded.
  • The computer must already have Ollama and qwen3:4b-instruct installed.
  • Ollama reads the report and evidence supplied by the app; it does not connect directly to REDCap.
  • Internet is still required to retrieve assessment data from REDCap after startup or save changes to REDCap.

Assistant troubleshooting

  • The application attempts to start Ollama automatically.
  • If the local server connection drops during an assistant request, the browser waits up to 90 seconds, reconnects, and retries once. Keep the page open.
  • If the executable remains stopped, restart it, refresh the browser page, sign in if required, and regenerate the report. A browser cannot launch a stopped Windows executable.
  • If Local AI is unavailable, close unused programs and restart the assessment executable.
  • Confirm PowerShell command ollama list shows qwen3:4b-instruct.
  • Use a focused question when the selected report is very large.
  • Run only one copy of the executable. Background copies can prevent an application update.

Finish safely

  • Save the active item and wait for confirmation.
  • Use Log out.
  • Data loaded from REDCap is not saved again merely because you log out.
  • Do not share accounts, .env, tokens, or screenshots containing credentials.
  • Do not delete or rename REDCap records without authorization. Verify the record ID, country, reporting period, and title first.
  • Report incorrect assignments, country information, or exact error messages to the administrator.
